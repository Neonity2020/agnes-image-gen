第 5 章：接入 Agnes 模型能力

目标：把 UI 任务变成可靠的 HTTP 调用，并将供应商协议隔离在 src/lib/agnes.ts。

1. 明确客户端配置的安全边界

本项目使用 Vite 环境变量选择 API 基址和模型名：

VITE_AGNES_API_BASE=https://apihub.agnes-ai.com/v1
VITE_AGNES_TEXT_MODEL=agnes-2.0-flash
VITE_AGNES_IMAGE_MODEL=agnes-image-2.1-flash
VITE_AGNES_VIDEO_MODEL=agnes-video-v2.0

Vite 会把 VITE_ 变量暴露给浏览器代码。它们适合公开的端点和模型选择，不适合保存服务端密钥。这里的 API Key 由用户输入后存到当前浏览器；生产级密钥托管需要下一阶段的服务端代理。

2. 先做一个统一请求函数

不要让文本、图像、视频函数各自处理 fetch、超时和错误。统一入口使三种能力拥有相同的失败语义：

async function request(path: string, init: RequestInit, timeoutMs = 360_000) {
  const controller = new AbortController()
  const timeout = window.setTimeout(() => controller.abort(), timeoutMs)
  try {
    const response = await fetch(`${API_BASE}${path}`, { ...init, signal: controller.signal })
    const payload = await response.json().catch(() => ({}))
    if (!response.ok) throw new Error(payload.error?.message ?? `请求失败（HTTP ${response.status}）`)
    return payload
  } finally {
    window.clearTimeout(timeout)
  }
}

注意 finally：即使请求失败或 JSON 无法解析，也必须取消定时器。不同任务可以传不同超时；视频创建和轮询通常比文本更长。

3. 封装认证和文本请求

请求头只有一个来源，避免某个调用遗漏 Content-Type 或 Bearer Token：

function headers(apiKey: string) {
  return { Authorization: `Bearer ${apiKey}`, "Content-Type": "application/json" }
}

export async function generateText(prompt: string, apiKey: string, history: ChatMessage[]) {
  return request("/chat/completions", {
    method: "POST", headers: headers(apiKey),
    body: JSON.stringify({ model: TEXT_MODEL, messages: [
      { role: "system", content: "You are Agnes, a helpful assistant." },
      ...history, { role: "user", content: prompt },
    ] }),
  })
}

历史由第 8 章的当前会话产生；API 适配层只接受已经整理好的 ChatMessage[]，不关心 React 状态。

4. 处理不同媒体响应形状

图片和视频服务可能返回 URL、base64，或位于嵌套字段。将这种不稳定性收敛到 mediaFromResponse，上层只接收 string | undefined：

function mediaFromResponse(payload: ApiPayload, kind: "image" | "video") {
  const result = payload.data?.[0]
  const url = result?.url ?? payload.video_url ?? payload.output?.url
  if (url) return url
  if (result?.b64_json) return `data:${kind === "image" ? "image/png" : "video/mp4"};base64,${result.b64_json}`
}

图生图时，将第 4 章处理过的 Data URL 作为可选字段传入图片请求；文本和视频请求不应接收这个参数。

5. 视频是“创建 + 轮询”的长任务

视频接口可能立即返回媒体 URL，也可能只返回 video_id 或 task_id。正确流程是：先创建任务；若没有 URL，每隔固定时间请求状态；出现 URL 时结束；状态为 failed/error/cancelled 或超过最大次数时抛出错误。

轮询属于外部协议，应该位于 agnes.ts，不能放在 React 组件中。否则组件会同时负责显示、任务状态和供应商网络细节。

6. 把技术异常翻译为用户反馈

用户不需要看到 AbortError。应用在 API 模块提供 normalizeGenerationError：超时提示稍后重试，网络 TypeError 提示检查网络/CORS，其余 Error 返回服务端消息。App 捕获异常后把该文本写入对应条目的 error 字段。

  4. 模拟 500、网络断开和 AbortError，确认 UI 得到不同的可读错误。

# Mission: Publish a From-Scratch Agnes Application Tutorial

## Why

Create a public, practical tutorial that enables developers to reproduce this browser-based multimodal Agnes application from an empty Vite project. The finished material should make the architecture understandable enough for readers to adapt it to their own AI creation products.

## Success looks like

- A reader can build and deploy a working text, image, and video creation application.
- A reader can explain the flow from React UI to LangGraph and the Agnes API.
- A reader can add multi-turn, locally persisted conversations without mixing concurrent results.

## Constraints

- Teach from this repository's implementation and use short, independently usable chapters.
- Use Chinese instructional content; keep Markdown filenames in English.
- Keep all API-key guidance explicit about browser-side exposure.

## Out of scope

- User accounts, server-side authentication, billing, and cloud data synchronization.

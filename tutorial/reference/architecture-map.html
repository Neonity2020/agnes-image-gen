Agnes 应用架构速查表

React UI → App.tsx → lib/agent.ts → lib/agnes.ts → Agnes API ↓ ↑ localStorage ← lib/storage.ts

模块职责

src/main.tsx
挂载 React 根组件并加载全局样式。
src/App.tsx
持有当前会话、表单与任务状态；协调 UI、存储和 Agent。
src/components/
展示层：侧栏、会话、提示词编辑器和设置弹窗。
src/lib/agent.ts
根据 text、image、video 路由任务。
src/lib/agnes.ts
构造 HTTP 请求、解析模型响应、轮询视频任务并标准化错误。
src/lib/storage.ts
保存 API Key 与会话，兼容旧本地数据。
src/types.ts
定义生成记录、消息条目、会话和聊天上下文的共享类型。

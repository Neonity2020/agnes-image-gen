项目初始化检查表

  1. Node.js 满足项目要求：>=20.19.0 || >=22.12.0。
  2. 使用 pnpm create vite@latest 创建 react-ts 项目。
  3. 安装 React、TypeScript、Vite、@vitejs/plugin-react、Tailwind v4 与 @tailwindcss/vite。
  4. 在 vite.config.ts 注册 React 和 Tailwind 插件。
  5. 为 @/* 同时配置 Vite alias 与 TypeScript paths。
  6. 建立 src/components、src/lib 和 src/types.ts。
  7. 运行 pnpm typecheck、pnpm build，两者均成功后再进入 UI 开发。

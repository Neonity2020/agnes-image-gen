从零构建 Agnes 多模态创作应用：课程大纲

课程定位

通过复刻本仓库的核心能力，学习如何构建一个纯浏览器端的多模态 AI 创作应用：文本问答、文生图、图生图、视频生成，以及可持续的多轮会话。本课程面向具备 JavaScript 基础、希望系统实践 React 与 AI 应用开发的开发者。

学习成果

完成课程后，你将能够搭建并部署一个使用 Agnes API 的 Vite + React + TypeScript 应用，理解客户端 Agent 编排、媒体交互、会话上下文与本地持久化的完整链路。

第 1 章：认识目标应用与技术架构

拆解界面、客户端 Agent、Agnes API 与浏览器存储的职责，产出应用流程图与领域词汇表。

第 2 章：初始化 Vite + React + TypeScript 工程

配置 Vite、TypeScript、路径别名与 Tailwind CSS v4，产出可运行的应用骨架。

第 3 章：搭建界面与设计系统

使用 shadcn/ui、Radix 与 Tailwind 构建静态创作工作台。

第 4 章：设计生成任务与表单交互

实现多模式任务表单、参考图上传、加载态与并发限制。

第 5 章：接入 Agnes 模型能力

封装文本、图像、视频生成请求及统一错误处理。

第 6 章：用 LangGraph 编排多模态 Agent

建立路由图，将生成模式映射到正确的 Agent 节点。

第 7 章：渲染对话与媒体结果

完成文本、图片、视频、失败状态和图生图操作的结果流。

第 8 章：实现多轮对话与线程管理

实现多线程、多轮上下文与并发任务的安全处理。

第 9 章：浏览器持久化与数据迁移

用 localStorage 实现可恢复的本地优先应用。

第 10 章：质量保障、构建与部署

验证构建、分析客户端风险并配置 Netlify 静态部署。

课程项目与延伸练习

  • 为会话增加重命名、搜索、导出与清空功能。
  • 增加流式文本输出或任务取消机制。
  • 将敏感请求迁移到服务端代理，并加入身份认证与云端同步。

附录

使用 Codex 构建项目备忘录：从任务说明、计划、实现、验证到提交的协作工作流。

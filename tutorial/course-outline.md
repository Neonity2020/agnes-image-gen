# 从零构建 Agnes 多模态创作应用：课程大纲

## 课程定位

通过复刻本仓库的核心能力，学习如何构建一个纯浏览器端的多模态 AI 创作应用：文本问答、文生图、图生图、视频生成，以及可持续的多轮会话。本课程面向具备 JavaScript 基础、希望系统实践 React 与 AI 应用开发的开发者。

## 学习成果

完成课程后，你将能够搭建并部署一个使用 Agnes API 的 Vite + React + TypeScript 应用，理解客户端 Agent 编排、媒体交互、会话上下文与本地持久化的完整链路。

## 第 1 章：认识目标应用与技术架构

- 拆解用户界面、客户端 Agent、Agnes API 与浏览器存储的职责。
- 理解为什么本项目不需要自建服务端，以及这种架构的安全边界。
- 产出：应用流程图与领域词汇表。

## 第 2 章：初始化 Vite + React + TypeScript 工程

- 配置 Vite、TypeScript、路径别名 `@/` 与 Tailwind CSS v4。
- 组织 `src/components`、`src/lib`、`src/types.ts` 的模块边界。
- 产出：可运行的应用骨架。

## 第 3 章：搭建界面与设计系统

- 使用 shadcn/ui、Radix 与 Tailwind 构建侧栏、主工作区、设置弹窗和响应式布局。
- 设计可复用的按钮、输入框、滚动区域与 Toast 反馈。
- 产出：静态创作工作台。

## 第 4 章：设计生成任务与表单交互

- 定义文本、图像、视频三种 `GenerationMode`。
- 实现提示词输入、尺寸选择、参考图上传、加载态与并发任务限制。
- 产出：可提交的多模式任务表单。

## 第 5 章：接入 Agnes 模型能力

- 配置 `VITE_AGNES_*` 环境变量与 API Key 设置。
- 封装文本、图像、视频生成请求及统一错误处理。
- 产出：端到端的单次生成能力。

## 第 6 章：用 LangGraph 编排多模态 Agent

- 建立 `route → write / draw / animate` 图结构。
- 将界面中的生成模式映射到正确的 Agent 节点。
- 产出：可扩展的客户端 Agent 模块。

## 第 7 章：渲染对话与媒体结果

- 定义 `ConversationEntry` 与生成结果类型。
- 实现文本 Markdown、图片、视频、失败状态和“以图生图”操作。
- 产出：完整的创作结果流。

## 第 8 章：实现多轮对话与线程管理

- 设计 `Conversation`、当前会话 ID 与线程标题/更新时间。
- 仅提取当前线程最近成功的文本问答作为模型上下文。
- 安全处理并发任务完成、切换线程与删除线程。
- 产出：支持多线程、多轮上下文的对话体验。

## 第 9 章：浏览器持久化与数据迁移

- 使用 `localStorage` 保存 API Key、会话与生成历史。
- 为存储异常、容量限制、旧数据结构迁移设置保护逻辑。
- 产出：刷新后可恢复的本地优先应用。

## 第 10 章：质量保障、构建与部署

- 使用 `pnpm typecheck`、`pnpm build` 验证项目。
- 分析客户端密钥暴露风险、包体积警告与可优化点。
- 配置 Netlify 静态部署。
- 产出：可部署版本与发布检查清单。

## 课程项目与延伸练习

- 为会话增加重命名、搜索、导出与清空功能。
- 增加流式文本输出或任务取消机制。
- 将敏感请求迁移到服务端代理，并加入身份认证与云端同步。
